# Local Sample Data

Place prepared CoMotion asset folders here for local development. Each folder
must contain `frames.bin`; `asset.json` and `thumbnail.jpg` are optional.

The sample payloads are intentionally ignored by Git because they are large.
The smaller asset used by the checked-in example scene is stored separately
under `FabricScenes/947B44F8-C4C3-4666-93B5-73BD71CE231A`.
